# 漏洞评分规则

供报告归档的阶段 2（过滤与定级）使用。原则：**按实际影响定级，证据优先于推测，不夸大不压低**。
定级只依据 finding 自身的 PoC/证据，证据无法支撑的影响不得计入。

---

## 等级定义

### 🔴 严重（满足任一）

- 核心业务系统 RCE / 命令执行 / 代码执行（有 `id`、`whoami` 或等价回显证据）。
- 数据库接管：任意 SQL 执行、DBA 权限、可直接读写核心业务库。
- 核心业务未授权访问：完全无需认证即可操作支付、账户、管理后台等核心数据或功能。
- 大规模敏感数据泄露：≥1 万条个人信息，或可直接接管系统的凭据/密钥批量泄露。
- 任意用户账户接管：密码重置逻辑缺陷、验证码绕过等可接管任意用户账户。
- 域名 / 主机接管：DNS 劫持、任意文件写入 getshell 等。

### 🟠 高危（满足任一）

- 敏感数据泄露：<1 万条个人信息、订单/支付数据、内部敏感文档。
- 垂直越权：低权限账号可执行管理员功能。
- 认证绕过并访问受保护数据：绕过登录/验证码进入受保护资源。
- 任意文件读取/下载：配置文件、源码、凭据文件等。
- SQL 注入（受限）：仅联合/盲注可用，未达 DBA/接管程度。
- SSRF 可达内网并可读取数据或攻击内网服务。
- 存储型 XSS 位于高流量页面（管理后台、主站用户可见页面）。

### 🟡 中危（满足任一）

- 水平越权（IDOR）：访问同权限级别其他用户的数据，且涉及敏感信息。
- 重要页面的反射型 XSS 且可自动触发（无需额外点击）。
- 逻辑漏洞：参数/价格/数量篡改等，影响有限且未证明直接资金损失。
- 可进一步利用的信息泄露：源码、含密钥或内网地址的配置。
- 非核心功能的未授权访问。
- 文件上传但未直接 getshell（需结合其他漏洞利用）。
- 可覆盖/删除线上存储桶文件（NOS/OSS/S3 等生产桶）；若证明可覆盖前端资源进一步利用或读取敏感数据，按实际影响升级。

### 🟢 低危（满足任一）

- 无法进一步利用的信息泄露：版本号、调试页、SVN/.git 残留（无敏感内容）。
- self-XSS、需受害者主动点击/扫码才触发的反射型 XSS。
- 无敏感数据返回的 JSONP。
- 已知组件版本漏洞但无 PoC 证明当前环境可利用。
- 普通存储桶文件上传：仅能上传至普通（非生产）存储桶，未证明可读取敏感数据或进一步利用。
- 间接利用的凭据泄露：如 client_secret 明文泄露于 URL、OAuth 回调走 HTTP（凭据降级），需 MITM 位置或进一步组合才能利用，未证明实际接管账户/系统。
- 其他有证据但无实际利用影响的缺陷。

## 评分调整规则

先按「等级定义」确定基准等级，再按下表一次性调整（多项叠加时合并考虑，最多调 1 级）：

| 因素 | 调整 |
|------|------|
| 利用需要管理员/高权限凭据前提 | 降 1 级 |
| 需要受害者交互（点击链接/扫码/打开文件） | 降 1 级 |
| 影响核心业务（支付/账户/主数据） | 升 1 级 |
| 仅影响内部测试系统或非生产环境 | 降 1 级 |
| 凭据/敏感信息泄露但利用路径间接（需 MITM 网络位置/需组合其他条件，无直接接管证明） | 降 1 级或定低危 |

- 调整后不超出「严重」上限、不低于「低危」下限。
- 证据不支持的影响维度（如"理论上可读库"但无回显证据）不作为升级依据。

---

## 攻击链评分规则

- 攻击链整体定级 = 链条**最终达成影响**的等级（如 信息泄露 → SSRF → RCE，按严重定级）。
- 链内子漏洞不单独定级，以 N.x 层级展开在主漏洞下。
- 仅当漏洞间存在因果利用依赖时才按链处理；无依赖的漏洞各自独立定级。

## 剔除标准（阶段 2 过滤依据）

满足任一即剔除：

1. **扫描器误报**：工具上报但证据经核对不成立（响应特征不符、payload 未实际执行）。
2. **证据不支持结论**：finding 的 PoC/截图/响应无法支撑其声称的漏洞类型或影响。
3. **无实际利用影响的纯信息类条目**：版本号、banner 等纯信息且无法进一步利用。
4. **非本任务目标的发现**：测试对象不在任务范围内的条目。
5. **安全响应头缺失**：HSTS / CSP / X-Frame-Options / X-Content-Type-Options 等 HTTP 安全响应头缺失，无对应已确认可利用漏洞。
6. **Web 指纹泄露**：仅暴露框架 / 中间件 / 服务器类型与版本等 Web 指纹，无法进一步利用。
7. **CORS 配置缺陷**：CORS 配置不当，无敏感数据返回；PoC 已演示跨域读取敏感数据的除外，按实际影响定级。
8. **无法进一步利用的报错堆栈**：报错返回堆栈/异常信息，仅暴露类名、方法名、路径等基础设施信息，不含敏感数据且无法进一步利用。
9. **无法进一步利用的 actuator 泄露**：Spring Boot /health、/info 等 actuator 端点可访问，仅暴露健康状态/版本等基础信息；/env、/heapdump、/configprops 等可泄露凭据或敏感数据的端点除外，按实际影响定级。
10. **前端加密算法泄露**：仅暴露前端使用的加密算法/模式（算法本身不构成秘密）；同时泄露硬编码密钥/IV 或可据此解密的除外，按实际影响定级。

不得剔除：

- 等级低但证据真实的漏洞 → 保留，按规则定低危。
- 定级有争议但证据完整的条目 → 保留，按本规则重新定级。
